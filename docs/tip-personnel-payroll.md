# Tip payouts, time, and payroll review

Connecteam sync writes confirmed roster mappings into `tip_employee_hours` as weekly decimals. The Tip Payout screen can also copy hours from CMS Time Clock or accept a manager's manual hours. Those paths write the same weekly row; the most recent write wins. The source and manual override are not stored separately, so verify the hours before approval. Payroll timesheets remain a separate, manager approved record.

Migration 154 establishes approved tip snapshots and their revision history. A manager saves the tip totals and hours, then selects **Approve weekly payout**. The server recalculates against the saved rows, validates the preview, and stores the roster IDs, names, hours, and per-person tip totals. Edits to the weekly totals, hours, or roster eligibility invalidate approval. Managers can refresh and approve the corrected week again; prior versions remain in `tip_payout_approval_history`.

An employee sees only their approved tip payouts in **My Tip Payouts** on the dashboard after their roster person is explicitly linked to their account. This is a tip statement, not an official Gusto paystub. Unlinked staff and unapproved weeks show no amount. Owners and managers have the same personal view.

The Personnel **Payroll review CSV** reads approved tip snapshots by roster ID → account ID. It refuses unlinked payouts, duplicate account names, and weeks that straddle the pay period. The tip column is deliberately called `Tip Total (Review)`: the existing combined pool does not say which dollars were already handed out and which Gusto should pay. The CSV is **not a certified Gusto import**. Choose and check Cash tips versus Paycheck tips in Gusto before payroll. Direct export will need a durable Gusto employee ID map, Gusto API access, and an explicit already-paid versus to-be-paid allocation.

Payroll destinations are separate from this approved source of truth. The existing QuickBooks Online integration imports chart of accounts and budget actuals; it does not currently send payroll. Intuit's TimeActivity API can receive employee time with payroll compensation references for eligible QuickBooks Payroll customers, but that does not establish an API path for paying or reporting tips. Verify tip-write support and access before adding a QuickBooks Payroll destination. Add Gusto only after its write permissions, employee IDs, tip earning types, and safe retry behavior are verified. Keep the provider-neutral review CSV for other payroll services.

Before staff rollout, test one linked account with a complete week: Connecteam sync → verify weekly hours → save totals → approve → see the amount on that account's dashboard → edit an hour and confirm the amount disappears → reapprove. Compare the review CSV with the Gusto payroll preview. Do not treat the review CSV as proof that Gusto has paid or reported tips.
